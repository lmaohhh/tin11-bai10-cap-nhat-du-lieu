## Điều khiển

| Phím | Tác dụng |
|---|---|
| `→` `Space` `PageDown` | Trang sau |
| `←` `PageUp` | Trang trước |
| `O` hoặc `Esc` | Tổng quan 12 trang (bấm vào thẻ để nhảy) |
| `F` | Toàn màn hình |
| `B` | Tắt màn hình |
| `N` | Ghi chú cho người trình bày |
| `R` | Đặt lại hiệu ứng ở trang hiện tại |

Trang 6 và 7 có thao tác trực tiếp: chạm ô **0** để xoá, chạm từ **Hồng** để sửa thành **Hoàng**; chạm lần nữa để hoàn tác.
